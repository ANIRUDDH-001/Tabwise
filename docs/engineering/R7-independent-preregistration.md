# R7 independent assessment preregistration — prepared, not registered

No withheld labels are present in this document or implementation packet. No R7 result is asserted. The owner assigns an independent custodian/assessor who did not implement, tune or run the candidate's development tests. Existing PLAN R3/R7 criteria remain authoritative; no threshold or kill criterion changes here.

1. Before any withheld execution, the custodian privately freezes task source, labels, expected completion/localization, control assignment, stopping rules and scoring rubric. Publish only a salted package commitment and opaque case IDs to the implementer. Keep the salt and labels outside all implementation worktrees, prompts, source maps and developer logs. Custodian records custody/access history and hashes. Any exposure makes that case development data; replace it through the custodian before scoring.
2. Bind preregistration to the exact candidate commit and cumulative source manifest; prompt bytes/hash, model ID/mode/provider version, parameters, fixture/plan/spec/source digests, verifier executable/root hashes and qualification scope. Runtime provider revision is unavailable until independently measured. A source/prompt/model change invalidates the assessment freeze and requires a new disclosure and preregistration; do not silently tune and re-score.
3. Freeze healthy/broken and correct/wrong patch controls with the same-model arms in the existing R2 plan. Keep independent outcome labels hidden. Correct patches must rescue the withheld task on a distinct source-bound rerun; wrong patches must not be marked solved. A failure on healthy or unaffected steps, wrong-patch false success, leakage, missing evidence or control-explained divergence prevents the corresponding causal/repair claim under the existing PLAN.
4. Require authentic baseline and distinct rerun identity: repository, workflow, ref, revision, actor and numeric IDs, run/attempt, product request/spec/plan/page/session, fixture and exact patch hashes. Require raw speech/action journals, clock/sequence coverage, immutable manifests, custody/OS census and physical-quiescence uncertainty, source export, independent signature checks and source-qualified native evidence. Titles, artifact names, predicted speech, mock flags and workflow-origin signatures alone cannot establish runtime qualification.
5. Negative controls: missing/duplicate/wrong attestation, altered archive/source/plan/spec, cross-owner data, stale/expired claims, run/attempt substitution, uncertain dispatch, duplicate ingestion, incomplete capture, missing speech or metadata, wrong patch and forged result. Every refusal retains its evidence and reason. No automatic second POST or paid retry is permitted to rescue a scored case.
6. Freeze model predictions before unsealing labels using the existing R2 preparation/prediction-freeze contracts. The assessor independently downloads the exact source-bound packet and native artifacts, verifies signatures and hashes, reconstructs findings and patch effects, then opens private labels and scores against the frozen rubric. Preserve failures, abstentions, aborted runs and unaffected-step regressions. The implementation process cannot write the independent conclusion.
7. Deliver an assessor-owned report bound to candidate/source/prompt/model/task commitments, native run IDs and complete negative results. Record reviewer identity, conflicts, custody, missing evidence, outcome and signature/reference. Reproducible engineering PASS may be reported separately; no R7 PASS until this independent protocol and the existing acceptance criteria are actually satisfied.

Unfilled prerequisites: independent assessor, withheld commitment/private labels, exact candidate freeze acknowledgement, authentic R2 paired controls, authentic R3 baseline/distinct rerun, independent scoring/report. All remain null in the companion draft. Development Fernway fixtures and the local replay are not withheld assessments.
